# Formal claim audit

All general proofs are mathematical, not mechanically verified implementation proofs.

1. **Source bridge:** Alpha maps Java string references to bounded ASCII contents and preserves
primitive Boolean values. Under the accepted pure grammar, related normal entry state, and API/
loader/normalization premises, translated expressions and normalized queries agree. No reference
identity, reachability, actual JVM member-array, or whole-classpath theorem is claimed.
2. **Finite certificate:** Acceptance against a separately supplied source establishes every
expression and probe value for all external/internal assignments, then exact aggregation.
Feasibility depends only on external coordinates. Robust possibility is forall h / exists r,
not a must-execute property. Flat infeasible rows are normalized from false feasibility plus an
empty outcome list to explicit infeasible probe actions.
3. **Existence:** A full decision tree exists for each total function; reduction/sharing preserves
its meaning. Acceptance also requires that the result fit separate file and graph admission bounds.
4. **Direct dispatch:** The independent replay checker accepts `(P, dispatch)` directly and proves
finite action identity. It does not require trusting an intermediate certificate or the lowerer.
The index is interpreted in P's ordered table. Java call behavior needs separate premises.
5. **Witness:** Given an accepted summary, sufficiency and one necessity world per coordinate
prove inclusion-minimal retention. The independent checker does not import production helpers.
A table absent only at 101 and 110 has minima {0} and {1,2}, selected by opposite orders. There
is no general unique least witness or minimum-cardinality guarantee.
6. **Complexity:** Checking enumerates 2^(external+internal) assignments. Table search and decision
walk costs remain explicit. Sharing reduces representation, not worst-case enumeration.

Executable evidence includes 68 unit tests, the fixed 664-case campaign, independent fixture
expectations, two separately described oracle investigations, and JVM controls. These do not
replace the specification, prove the host runtime, or eliminate construction bias.
